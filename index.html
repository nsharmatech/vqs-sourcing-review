Source, definitions and review rules

Source: Lakshan’s 90-day VQS supplier quote report, 19 Aug to 17 Nov 2026. Manufacturer labels are shown as recorded, so aliases can appear separately. Labels with missing manufacturer information are flagged for verification.

Quote rate is quoted request lines divided by all request lines. A request line is quoted if it has at least one qualifying supplier bid. A Quote ID can contain multiple part request lines, so the two counts measure different things. Confirm supplier approval, quantity, price, lead time and current availability with Trading.

The 50% quote-rate cutoff and the minimum of 3 distinct Quote IDs define the first review group for this dashboard. They are review rules for this analysis. Within each group, the default order starts with the largest count of unquoted request lines.
